# Velocoast Shade Solution — Client Brief Restructure

This version restructures the website around the services supplied in the client brief.

## Services
1. Car Park Shades
2. Tents (Exhibition, Safari, Camping, Dome & Event)
3. Premium Shade Sails
4. Wind Breakers
5. DIY Carports
6. Truck Tarpaulin Covers
7. Flatbed Pickup Covers
8. Parasols
9. Box Covers
10. Repair Works & Re-Tensioning

The supplied client imagery is stored in `public/images/client/`.

SEO files and the existing React/Vite structure are retained. The service detail pages, contact form, portfolio and navigation now use the same service data source, so future edits only need to be made in `src/data/services.js`.
