# Velocoast Shade Solution

Mobile-first React/Vite website for Velocoast Shade Solution, a Kilifi-based tent, shade and canvas fabrication/repair service serving projects across Kenya.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production check

```bash
npm run build
npm run preview
```

## Before deployment

1. Replace the placeholder sitemap domain in `public/sitemap.xml` and `public/robots.txt` with the final live domain.
2. Add real project photographs to the portfolio and service pages.
3. Add the final logo if desired.
4. Submit the live sitemap to Google Search Console after deployment.

The site does not require a backend. Quote enquiries are prepared and sent through WhatsApp.
